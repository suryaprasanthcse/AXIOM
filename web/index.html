DEPLOY GATE FOR AI CODING AGENTS ON AWS

AXIOM

Agents hold proofs, not permissions.

An AI agent with your AWS keys can do anything those keys allow. With AXIOM, the agent's own identity is view-only. To change anything, it submits a plan. CloudFormation computes the diff, deterministic axioms and IAM Access Analyzer's automated reasoning decide, and AWS STS mints a credential that lasts 15 minutes and can execute that one change set. Any other call is denied by IAM itself. There is no model in the security path: the AI is what AXIOM governs, never what it trusts.

ARENA

Try to talk AXIOM into something destructive. Pick a scenario or edit the template, then run the axioms. Every run creates a real CloudFormation change set against the live stack axiom-arena-baseline. Arena change sets are evaluated and recorded, never executed, and never receive a credential.

LEDGER

Every verdict AXIOM issues, from agents and from the arena. Each record carries a SHA-256 proof hash. When an agent receives a credential, the same hash is attached to its STS session as a tag, so CloudTrail ties every executed change back to its proof.

HOW IT WORKS

  1. 01 / VIEW-ONLY AGENT. The agent's IAM role (axiom-agent-role) can read the account but has no write path into CloudFormation and cannot assume other roles. Its only way to change anything is to ask AXIOM, and it must declare up front which resources the change may touch. Intent becomes a machine-checked contract instead of a sentence.
  2. 02 / CLOUDFORMATION COMPUTES THE DIFF. The broker Lambda creates a change set using a dedicated CloudFormation service role. CloudFormation itself reports what will be added, modified, replaced or removed.
  3. 03 / AXIOMS AND AUTOMATED REASONING DECIDE. Deterministic rules and IAM Access Analyzer's custom policy checks, which use automated reasoning to prove what a policy can and cannot allow, set the verdict. The report restates exactly which check fired and why. No model is consulted, so there is nothing to prompt-inject: a template that says "ignore your rules" is just a string.
  4. 04 / A PROOF BECOMES A 15-MINUTE KEY. On ALLOW, AWS STS mints a session for axiom-executor-role with a session policy that allows cloudformation:ExecuteChangeSet on exactly that change set, tagged with the plan ID and proof hash. Only the broker can assume that role.
